# Google Ads Sunelys - test strict B2B - 2026-07-28

## Decision appliquee

Objectif: arreter la depense sur les recherches trop generalistes et repartir sur une intention plus proche d'un installateur PV qui veut deleguer une charge administrative.

Actions Google Ads deja appliquees le 2026-07-28:

- Campagne active `Search - Delegation admin PV installateurs`: budget baisse de `10,00 EUR / jour` a `3,00 EUR / jour`.
- Mots-cles actifs trop larges mis en veille:
  - `"declaration prealable photovoltaique"`;
  - `[declaration prealable photovoltaique]`;
  - `"declaration prealable panneaux solaires"`;
  - `"raccordement panneaux solaires"`;
  - `"raccordement panneau solaire"`.

## Correction d'intention

Ne pas viser `installateur` seul. Ce mot isole peut attirer quelqu'un qui cherche un poseur ou un artisan.

L'intention cible doit exprimer au moins une de ces idees:

- deleguer;
- sous-traiter;
- externaliser;
- confier un dossier;
- gestion administrative PV;
- prestataire administratif PV;
- DP, Consuel ou raccordement pour installateur.

## Mots-cles a privilegier

Priorite haute:

- `sous traitance administrative photovoltaique`;
- `delegation administrative photovoltaique`;
- `externalisation administrative photovoltaique`;
- `gestion administrative photovoltaique installateur`;
- `prestataire administratif photovoltaique`;
- `sous traitance dossier photovoltaique`;
- `sous traitance declaration prealable photovoltaique`;
- `prestataire declaration prealable photovoltaique`;
- `dossier consuel photovoltaique installateur`;
- `sous traitance consuel photovoltaique`;
- `prestataire raccordement enedis photovoltaique`;
- `sous traitance raccordement enedis`.

Types de correspondance:

- expression exacte;
- exact;
- pas de requete large pour l'instant.

## Mots-cles a eviter pour ce test

A eviter meme s'ils ont du volume:

- `declaration prealable photovoltaique`;
- `declaration prealable panneaux solaires`;
- `declaration panneau solaire`;
- `demande installation panneau solaire mairie`;
- `raccordement panneaux solaires`;
- `raccordement panneau solaire`;
- `consuel photovoltaique`.

Ces recherches peuvent etre bonnes pour le SEO, mais pas pour du SEA a petit budget sans qualification B2B explicite.
